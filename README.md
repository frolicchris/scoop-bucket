# BubbleFacts Scoop bucket

[Scoop](https://scoop.sh) bucket for [BubbleFacts](https://bubblefacts.frolic.org): short facts about the song you're playing, shown as bubbles in OBS. For musicians and DJs who stream.

```powershell
scoop bucket add bubblefacts https://github.com/frolicchris/scoop-bucket
scoop install bubblefacts/bubblefacts
```

The installer isn't signed yet, so Windows may warn the first time. The [Microsoft Store version](https://apps.microsoft.com/detail/9PP5TXRLTF4Z) opens with no warning.
